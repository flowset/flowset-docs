= Keycloak Setup
:description: Running Keycloak and setting up a realm, client, roles, and users for single sign-on to Flowset Control.

This page shows an example of setting up Keycloak as the identity provider for xref:oidc.adoc[single sign-on (SSO)] in Flowset Control. Configure Control first as described in xref:oidc.adoc[], then follow the steps below.

[[keycloak-setup]]
== Setting Up a Local Keycloak Instance

One of the most popular OpenID providers is Keycloak.
To explore the Jmix OIDC add-on, you can run Keycloak locally using Docker.

=== Running Keycloak with Docker

Use the following command to run a Keycloak instance via Docker on port 8180:

[source]
----
docker run -p 8180:8080 \
    -e KEYCLOAK_ADMIN=admin \
    -e KEYCLOAK_ADMIN_PASSWORD=admin \
    --name keycloak \
    quay.io/keycloak/keycloak:22.0 start-dev
----

See the https://www.keycloak.org/getting-started/getting-started-docker[Keycloak documentation] for more details.

Keycloak URL: http://localhost:8180

Admin credentials:

[source]
----
Username: admin
Password: admin
----

You can read about configuring a Keycloak instance in the https://www.keycloak.org/docs/latest/server_admin/[Server Administration Guide].

== Configuring Keycloak for Flowset Control

[[keycloak-realm]]
=== Creating a Realm

Log in to the Keycloak Admin Console and complete the following steps:

1. In the left panel, click *Add Realm*.
+
image::create-realm-1.png[align="center", width="1000"]
+
2. Enter a realm name, for example `flowset`.
3. Click *Create*.
+
image::create-realm-2.png[align="center", width="1000"]

[[keycloak-client]]
=== Creating a Client

A client represents the Flowset Control application that will use Keycloak for authentication.

1. Open *Clients* and click *Create*.
2. Specify parameters:
+
[cols="1,3", options="header", frame=none, grid=rows]
|===
| Parameter | Value

| *Client ID*
| `flowset-control`

| *Client Protocol*
| `openid-connect`
|===
+
image::create-client-1.png[align="center", width="900"]
+
3. In the *Capability config* section:
+
[cols="1,3", options="header", frame=none, grid=rows]
|===
| Parameter | Value

| *Client authentication*
| `ON`
|===
+
image::create-client-2.png[align="center", width="900"]
+
4. In the *Login Settings* section, set:
+
[cols="1,3", options="header", frame=none, grid=rows]
|===
| Parameter | Value

| *Valid Redirect URIs*
| `*` (development only)

| *Valid post logout redirect URIs*
| `*` (development only)

| *Web Origins*
| `*` (development only)
|===
+
image::create-client-3.png[align="center", width="900"]
+
After saving the client, go to the *Credentials* tab and copy the *Client Secret*.
This secret will be used in the Flowset Control configuration.
+
image::client-credentials.png[align="center", width="900"]

[[keycloak-roles]]
=== Creating Roles

Roles in Keycloak must match the role codes used in Jmix/Flowset Control.

1. Open *Realm roles* → *Add Role*.
2. Enter a role name, for example `system-full-access`.
3. Save the changes.
+
image::create-role.png[align="center", width="800"]

[[keycloak-users]]
=== Creating a User

1. Open *Users* → *Add User*.
2. Enter a username, for example `johndoe`.
3. Save.
+
image::create-user.png[align="center", width="800"]
+
After saving:

* On the *Credentials* tab, set a password for the user.
* On the *Role Mappings* tab, assign the `system-full-access` role.
+
image::create-user-credentials.png[align="center", width="800"]
+
image::assign-role.png[align="center", width="800"]

[[keycloak-mapper]]
=== Configuring a Role Mapper

To ensure roles are included in the ID Token, create a mapper:

1. Go to *Client scopes* → `roles` → *Mappers* → `realm roles`.
2. Click *Create* and fill in the fields:
+
[cols="1,3", options="header", frame=none, grid=rows]
|===
| Field | Value

| *Mapper Type* | `User Realm Role`
| *Token Claim Name* | `realm roles`
| *Claim JSON Type* | `String`
| *Add to ID token* | `ON`
| *Add to access token* | `ON`
| *Add to userinfo* | `ON`

|===
+
image::create-mapper-1.png[align="center", width="900"]
+
image::create-mapper-2.png[align="center", width="900"]
