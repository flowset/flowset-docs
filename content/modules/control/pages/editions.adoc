[[editions]]
= Flowset Control Editions
:navtitle: Compare Editions
:description: How the Community and Enterprise editions of Flowset Control differ: the features of each edition.

Flowset Control comes in two editions. The *Community* edition is free and open source: it lets you browse processes, instances, incidents, user tasks, decisions, and deployments. The *Enterprise* edition is commercial: it includes all Community features and additional features for analyzing and managing process execution.

Pages about Enterprise features are marked with the [.ee]#EE# badge in the documentation menu, and the page header shows the edition. How to install an Enterprise license is described in xref:license.adoc[].
