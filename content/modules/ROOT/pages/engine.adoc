= Process Engines
:navtitle: Process Engines
:description: Operaton is the recommended process engine for Flowset, backed by commercial support from Flowset as an Operaton partner. Engines with the Camunda 7 API are compatible as well.

Flowset tools work on top of a BPM process engine that executes processes and decisions. *Operaton* is the engine at the core of Flowset. Engines that share the Camunda 7 API are also compatible: Camunda 7, CIB seven, and Fluxnova.

[[operaton]]
== Operaton: the Recommended Engine

[.engine-primary]
****
[.engine-badge]#Recommended engine · Operaton partner#

Operaton is an open-source BPM engine and a community fork of Camunda 7. It executes BPMN 2.0 processes, evaluates DMN 1.3 decisions, and runs CMMN 1.1 cases. Flowset is developed and tested on Operaton first.

Flowset is an Operaton partner and provides commercial support for the engine: help with incidents and performance, fixes, upgrades, and migration from Camunda 7.

== What Operaton Does

* Executes BPMN processes: moves process instances through the diagram, stops at wait states such as user tasks and message events, and saves their state.
* Evaluates DMN decision tables, either from a business rule task or through the API.
* Runs jobs in the background: timers, asynchronous continuations, and retries after failures.
* Creates incidents when a job or an external task runs out of retries.
* Stores runtime and history data in a relational database.
* Provides a Java API for applications with an embedded engine and a REST API for remote clients.

== How Flowset Tools Work with Operaton

[cols="1,3,2", options="header"]
|===
| Tool | Role | Details

| Control
| Connects to one or more engines through their REST API. Shows processes, instances, incidents, jobs, decisions, and deployments, and lets you manage them.
| xref:control:connecting-engine.adoc[]

| Creates Spring Boot applications with an embedded engine in IntelliJ IDEA. Models BPMN and DMN diagrams and forms for the engine and generates delegate code.
| xref:studio:new-project-wizard.adoc[]

| Works with user tasks and starts processes through the engine REST API. Has no backend of its own.

* *Commercial support*: Flowset tools are developed and tested on this engine, and Flowset provides commercial support for the engine itself.
* *Compatible*: Flowset tools work with the engine through its Camunda 7 API. Flowset does not provide support for the engine itself; it is supported by its vendor or community.
