= What's New

Flowset has two release streams. Community releases cover the whole platform: one version, such as `2026.0`, applies to Flowset Control and Flowset Tasklist. Enterprise releases are versioned per product, for example Flowset Control Enterprise 2.0.0. Enterprise 1.0 and 1.1 correspond to Community 2025.0 and 2026.0. Starting with 2.0, Enterprise ships ahead of the platform, and some of its changes reach Community in a later release.

Flowset does not ship its own BPM engine. Control and Tasklist work with external engines: Camunda 7, Operaton, and compatible engines. The list of supported engines for each release is given on its page.

== Community

* xref:ROOT:whats-new/community/2026.0.adoc[]: reworked Control screens for decisions, processes, jobs, and incidents; Jmix 2.7; Studio update. Patch 2026.0.1 adds the Fluxnova engine and deployment to WildFly and JBoss EAP.
* xref:ROOT:whats-new/community/2025.0.adoc[]: the first stable release of Control and Tasklist. Patch Control 2025.0.1.

Release notes for all Community releases are published on GitHub:
https://github.com/flowset/flowset-control-community/releases[Control],
https://github.com/flowset/flowset-tasklist-react-community/releases[Tasklist].

== Enterprise

* xref:ROOT:whats-new/enterprise/2.0.adoc[]: Control 2.0.0 on Jmix 3 and Java 21, license key activation, AI assistant, history of process variable changes.
* xref:ROOT:whats-new/enterprise/1.1.adoc[]: Control 1.1.0 (matches 2026.0) with batch operations, decision evaluation, jobs, process instance modification, transaction boundaries, and predefined roles.
* xref:ROOT:whats-new/enterprise/1.0.adoc[]: Control 1.0.0 (matches 2025.0) with engine monitoring, heatmap, sending messages, and element documentation.
