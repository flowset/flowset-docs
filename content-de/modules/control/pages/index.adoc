== Hauptfunktionen

- **Verbindungsverwaltung:** Richten Sie mühelos Verbindungen zu verschiedenen BPM-Engines ein und wechseln Sie bei Bedarf zwischen ihnen.
- **Prozessdurchsicht:** Navigieren Sie durch die auf der Engine bereitgestellten Prozesse.
- **Prozessbereitstellung:** Stellen Sie eine neue Version eines Geschäftsprozesses mit einer praktischen Diagrammvorschau bereit.
- **Instanzverwaltung:** Verwalten Sie die derzeit auf der BPM-Engine laufenden Prozessinstanzen.
- **Verwaltung von Benutzeraufgaben:** Zeigen Sie Benutzeraufgaben an und weisen Sie sie neu zu.
