= Keycloak einrichten
:description: Keycloak starten und Realm, Client, Rollen und Benutzer für Single Sign-On in Flowset Control einrichten.

Diese Seite zeigt ein Beispiel für die Einrichtung von Keycloak als Identitätsanbieter für xref:oidc.adoc[Single Sign-On (SSO)] in Flowset Control. Konfigurieren Sie zuerst Control wie unter xref:oidc.adoc[] beschrieben und folgen Sie dann den Schritten unten.

[[keycloak-setup]]
== Einrichten einer lokalen Keycloak-Instanz

Einer der beliebtesten OpenID-Anbieter ist Keycloak.
Um das Jmix OIDC Add-on zu erkunden, können Sie Keycloak lokal mit Docker ausführen.

=== Keycloak mit Docker ausführen

Verwenden Sie den folgenden Befehl, um eine Keycloak-Instanz über Docker auf Port 8180 auszuführen:

[source]
----
docker run -p 8180:8080 \
    -e KEYCLOAK_ADMIN=admin \
    -e KEYCLOAK_ADMIN_PASSWORD=admin \
    --name keycloak \
    quay.io/keycloak/keycloak:22.0 start-dev
----

Weitere Einzelheiten finden Sie in der https://www.keycloak.org/getting-started/getting-started-docker[Keycloak-Dokumentation].

Keycloak-URL: http://localhost:8180

Administrator-Anmeldedaten:

[source]
----
Username: admin
Password: admin
----

Informationen zur Konfiguration einer Keycloak-Instanz finden Sie im https://www.keycloak.org/docs/latest/server_admin/[Server Administration Guide].

== Konfiguration von Keycloak für Flowset Control

[[keycloak-realm]]
=== Erstellen eines Realms

Melden Sie sich an der Keycloak Admin Console an und führen Sie die folgenden Schritte aus:

1. Klicken Sie im linken Bereich auf *Add Realm*.
+
image::create-realm-1.png[align="center", width="1000"]
+
2. Geben Sie einen Realm-Namen ein, zum Beispiel `flowset`.
3. Klicken Sie auf *Create*.
+
image::create-realm-2.png[align="center", width="1000"]

[[keycloak-client]]
=== Erstellen eines Clients

Ein Client repräsentiert die Anwendung Flowset Control, die Keycloak zur Authentifizierung verwenden wird.

1. Öffnen Sie *Clients* und klicken Sie auf *Create*.
2. Geben Sie die Parameter an:
+
[cols="1,3", options="header", frame=none, grid=rows]
|===
| Parameter | Wert

| *Client ID*
| `flowset-control`

| *Client Protocol*
| `openid-connect`
|===
+
image::create-client-1.png[align="center", width="900"]
+
3. Im Abschnitt *Capability config*:
+
[cols="1,3", options="header", frame=none, grid=rows]
|===
| Parameter | Wert

| *Client authentication*
| `ON`
|===
+
image::create-client-2.png[align="center", width="900"]
+
4. Legen Sie im Abschnitt *Login Settings* Folgendes fest:
+
[cols="1,3", options="header", frame=none, grid=rows]
|===
| Parameter | Wert

| *Valid Redirect URIs*
| `*` (nur für die Entwicklung)

| *Valid post logout redirect URIs*
| `*` (nur für die Entwicklung)

| *Web Origins*
| `*` (nur für die Entwicklung)
|===
+
image::create-client-3.png[align="center", width="900"]
+
Wechseln Sie nach dem Speichern des Clients zur Registerkarte *Credentials* und kopieren Sie das *Client Secret*.
Dieses Secret wird in der Konfiguration von Flowset Control verwendet.
+
image::client-credentials.png[align="center", width="900"]

[[keycloak-roles]]
=== Erstellen von Rollen

Die Rollen in Keycloak müssen mit den Rollencodes übereinstimmen, die in Jmix/Flowset Control verwendet werden.

1. Öffnen Sie *Realm roles* → *Add Role*.
2. Geben Sie einen Rollennamen ein, zum Beispiel `system-full-access`.
3. Speichern Sie die Änderungen.
+
image::create-role.png[align="center", width="800"]

[[keycloak-users]]
=== Erstellen eines Benutzers

1. Öffnen Sie *Users* → *Add User*.
2. Geben Sie einen Benutzernamen ein, zum Beispiel `johndoe`.
3. Speichern Sie.
+
image::create-user.png[align="center", width="800"]
+
Nach dem Speichern:

* Legen Sie auf der Registerkarte *Credentials* ein Passwort für den Benutzer fest.
* Weisen Sie auf der Registerkarte *Role Mappings* die Rolle `system-full-access` zu.
+
image::create-user-credentials.png[align="center", width="800"]
+
image::assign-role.png[align="center", width="800"]

[[keycloak-mapper]]
=== Konfigurieren eines Role Mappers

Um sicherzustellen, dass die Rollen im ID Token enthalten sind, erstellen Sie einen Mapper:

1. Gehen Sie zu *Client scopes* → `roles` → *Mappers* → `realm roles`.
2. Klicken Sie auf *Create* und füllen Sie die Felder aus:
+
[cols="1,3", options="header", frame=none, grid=rows]
|===
| Feld | Wert

| *Mapper Type* | `User Realm Role`
| *Token Claim Name* | `realm roles`
| *Claim JSON Type* | `String`
| *Add to ID token* | `ON`
| *Add to access token* | `ON`
| *Add to userinfo* | `ON`

|===
+
image::create-mapper-1.png[align="center", width="900"]
+
image::create-mapper-2.png[align="center", width="900"]
