= Flowset Studio
:navtitle: Studio
:page-layout: module-home

== Hauptfunktionen

* Explizite Projektstruktur
* Navigation zwischen prozessbezogenen Objekten
* Lokales und entferntes Arbeiten mit Prozessen
* Intelligente Suche
* Geschäftsprozess-Modellierer
* Intelligente Codevervollständigung und Validierungen
* Generierung von Services und Java Delegates
