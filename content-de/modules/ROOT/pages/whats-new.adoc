= Was ist neu

Flowset hat zwei Release-Linien. Community-Releases umfassen die gesamte Plattform: Eine Version wie `2026.0` gilt für Flowset Control und Flowset Tasklist. Enterprise-Releases werden pro Produkt nummeriert, zum Beispiel Flowset Control Enterprise 2.0.0. Enterprise 1.0 und 1.1 entsprechen Community 2025.0 und 2026.0. Ab Version 2.0 erscheint Enterprise vor der Plattform, und ein Teil der Änderungen kommt erst in einem späteren Release in die Community-Edition.

Flowset enthält keine eigene BPM-Engine. Control und Tasklist arbeiten mit externen Engines: Camunda 7, Operaton und kompatiblen Engines. Welche Engines ein Release unterstützt, steht auf der jeweiligen Seite.

== Community

* xref:ROOT:whats-new/community/2026.0.adoc[]: überarbeitete Control-Bildschirme für Entscheidungen, Prozesse, Jobs und Vorfälle; Jmix 2.7; Studio-Update. Patch 2026.0.1 ergänzt die Fluxnova-Engine und die Bereitstellung in WildFly und JBoss EAP.
* xref:ROOT:whats-new/community/2025.0.adoc[]: das erste stabile Release von Control und Tasklist. Patch Control 2025.0.1.

Die Release Notes aller Community-Releases werden auf GitHub veröffentlicht:
https://github.com/flowset/flowset-control-community/releases[Control],
https://github.com/flowset/flowset-tasklist-react-community/releases[Tasklist].

== Enterprise

* xref:ROOT:whats-new/enterprise/2.0.adoc[]: Control 2.0.0 auf Jmix 3 und Java 21, Aktivierung per Lizenzschlüssel, KI-Assistent, Verlauf der Änderungen von Prozessvariablen.
* xref:ROOT:whats-new/enterprise/1.1.adoc[]: Control 1.1.0 (entspricht 2026.0) mit Batch-Operationen, Auswertung von Entscheidungen, Jobs, Prozessinstanz-Modifikation, Transaktionsgrenzen und vordefinierten Rollen.
* xref:ROOT:whats-new/enterprise/1.0.adoc[]: Control 1.0.0 (entspricht 2025.0) mit Überwachung der BPM-Engine, Heatmap, Senden von Messages und Dokumentation von Prozesselementen.
