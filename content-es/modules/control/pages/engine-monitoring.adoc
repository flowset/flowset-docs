[[monitoring]]
= Monitoreo del motor BPM

[NOTE, caption="Enterprise Feature"]
====
Esta funcionalidad está disponible exclusivamente en la edición *Flowset Control Enterprise*.
====

Flowset Control le permite ver el estado actual de los procesos de negocio en ejecución dentro del motor. Sin embargo, también resulta útil para un administrador de sistemas disponer de información sobre el estado general del sistema, como el número de núcleos de CPU, la memoria RAM disponible, el espacio en disco, etc. Esta información permite a los administradores recibir advertencias tempranas sobre el aumento de la carga. Combinado con el escalado automático o manual del sistema, Flowset Control proporciona una solución completa para gestionar motores de procesos de negocio.

[[monitoring-configuration]]
== Configuración del monitoreo

En la edición Enterprise, la vista de detalles del motor BPM se amplía con una sección específica de *Monitoreo*:

image::bpm-engine-monitoring.png[align="center", width="1440"]

=== Dashboard externo (URL)

* Especifique la URL de un dashboard de monitoreo externo (por ejemplo, https://grafana.com/[Grafana^]).
* Ejemplo: para Camunda, puede configurar un dashboard de Grafana y pegar aquí su URL.
* Proporciona navegación con un solo clic desde Flowset Control directamente al dashboard externo:
+
image::grafana-monitoring.png[align="center", width="1440"]

== Métricas integradas

* Marque la casilla *Enable* para activar la recopilación y visualización de métricas en Flowset Control.
* Campo *URL*: especifique el endpoint desde el que se obtendrán las métricas (por ejemplo, un endpoint de Spring Boot Actuator).
* Haga clic en *Generate* para cargar las métricas disponibles desde el endpoint especificado.
+
image::actuator-metrics.png[align="center", width="776"]

== Selección de métricas

* Seleccione las métricas deseadas marcando las casillas junto a sus nombres.
+
image::actuator-metrics-select.png[align="center", width="779"]

* Pase el cursor sobre el icono de signo de interrogación (?) para ver una breve descripción de cada métrica.

* Puede configurar etiquetas para cada métrica y así habilitar un monitoreo más granular de áreas específicas:
+
image::actuator-metrics-tags.png[align="center", width="802"]

[[viewing-metrics]]
== Visualización de métricas

. Navegue hasta la lista de xref:connecting-engine.adoc#bpm-engines[Motores BPM] en Flowset Control.
. Haga clic en *View metrics* para el motor deseado.
+
image::view-metrics.png[align="center", width="1254"]
. Se abrirá una ventana de diálogo:
+
image::metrics.png[align="center", width="962"]
* Todas las métricas configuradas y sus etiquetas.
* Valores actuales de las métricas.
* Un botón *Refresh* para actualizar los valores en tiempo real.

[NOTE]
====
Utilice el botón *External dashboard* para acceder rápidamente al dashboard de Grafana (u otro) configurado.

image::external-dashboard.png[align="center", width="855"]
====

[[quick-access-toolbar]]
== Barra de acceso rápido

Para un monitoreo ágil, utilice el selector de motores situado en la parte superior de la pantalla.

image::quick-access-monitoring.png[align="center", width="876"]

Esto le permite:

* Ver rápidamente las métricas del motor seleccionado.
* Navegar directamente al panel externo.
