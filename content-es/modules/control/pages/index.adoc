== Características principales

- **Gestión de conexiones:** permite configurar conexiones a distintos motores BPM y cambiar entre ellas según sea necesario.
- **Exploración de procesos:** permite navegar por los procesos desplegados en el motor.
- **Despliegue de procesos:** permite desplegar una nueva versión de un proceso de negocio con una vista previa clara del diagrama.
- **Gestión de instancias:** permite gestionar las instancias de proceso que se están ejecutando actualmente en el motor BPM.
- **Gestión de tareas de usuario:** permite visualizar tareas de usuario y reasignarlas.
