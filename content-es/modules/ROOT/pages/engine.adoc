= Motores de procesos
:navtitle: Motores de procesos
:description: Operaton es el motor de procesos recomendado para Flowset, con soporte comercial de Flowset como partner de Operaton. Los motores con la API de Camunda 7 también son compatibles.

Las herramientas de Flowset funcionan sobre un motor de procesos BPM que ejecuta procesos y decisiones. *Operaton* es el motor en el núcleo de Flowset. Los motores que comparten la API de Camunda 7 también son compatibles: Camunda 7, CIB seven y Fluxnova.

[[operaton]]
== Operaton: el motor recomendado

[.engine-primary]
****
[.engine-badge]#Motor recomendado · Partner de Operaton#

Operaton es un motor BPM de código abierto y un fork comunitario de Camunda 7. Ejecuta procesos BPMN 2.0, evalúa decisiones DMN 1.3 y ejecuta casos CMMN 1.1. Flowset se desarrolla y se prueba primero sobre Operaton.

Flowset es partner de Operaton y ofrece soporte comercial para el motor: ayuda con incidencias y rendimiento, correcciones, actualizaciones y migración desde Camunda 7.

[[engine-role]]
== Qué hace Operaton

* Ejecuta procesos BPMN: hace avanzar las instancias de proceso por el diagrama, se detiene en estados de espera como tareas de usuario y eventos de mensaje, y guarda su estado.
* Evalúa tablas de decisión DMN, desde una tarea de regla de negocio o a través de la API.
* Ejecuta trabajos en segundo plano: temporizadores, continuaciones asíncronas y reintentos tras fallos.
* Crea incidentes cuando un trabajo o una tarea externa agota sus reintentos.
* Almacena los datos de ejecución y del historial en una base de datos relacional.
* Ofrece una API Java para aplicaciones con motor embebido y una API REST para clientes remotos.

== Cómo trabajan las herramientas de Flowset con Operaton

[cols="1,3,2", options="header"]
|===
| Herramienta | Función | Más información

| Control
| Se conecta a uno o varios motores a través de su API REST. Muestra procesos, instancias, incidentes, trabajos, decisiones y despliegues, y te permite gestionarlos.
| xref:control:connecting-engine.adoc[]

| Studio
| Crea aplicaciones Spring Boot con motor embebido en IntelliJ IDEA. Modela diagramas BPMN y DMN y formularios para el motor y genera el código de delegados.
| xref:studio:new-project-wizard.adoc[]

| Tasklist
| Trabaja con tareas de usuario e inicia procesos a través de la API REST del motor. No tiene backend propio.
| xref:tasklist:connecting-engine.adoc[]
|===

* *Soporte comercial*: las herramientas de Flowset se desarrollan y se prueban sobre este motor, y Flowset ofrece soporte comercial para el propio motor.
* *Compatible*: las herramientas de Flowset funcionan con el motor a través de su API de Camunda 7. Flowset no ofrece soporte para el propio motor; lo soportan su proveedor o su comunidad.
