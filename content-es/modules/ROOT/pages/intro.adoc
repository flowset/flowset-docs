== ¿Qué es Flowset?

Flowset es una plataforma de automatización de procesos de negocio con un motor de ejecución propio y un conjunto de herramientas que cubren todo el ciclo de vida de una solución BPM.

=== Principios fundamentales

* **Compatibilidad con Camunda**
  Creemos que esta tecnología, que se ha convertido en un estándar de la industria, seguirá siendo relevante durante mucho tiempo.

* **Cumplimiento del estándar BPMN 2.0**
  Garantiza transparencia, previsibilidad y facilita la incorporación de nuevos especialistas.

* **Interoperabilidad**
  Flowset es compatible con las herramientas de modelado y desarrollo más populares.

* **Enfoque en la automatización de procesos de negocio**
  Flowset cubre el ciclo completo de la automatización de procesos: desde el diseño hasta la ejecución y el monitoreo.

* **Modularidad y apertura**
  Cada componente de la plataforma funciona de forma independiente y, en conjunto, aportan el máximo valor.

=== Componentes de la plataforma

==== Control
Una herramienta de código abierto para monitorear la ejecución de procesos de negocio. Es similar a Camunda Cockpit, pero ofrece funcionalidad ampliada.
Está construida sobre Jmix, un framework de código abierto. El código fuente está disponible en https://github.com/flowset/flowset-control-community[GitHub].

==== Studio
Un plugin para https://www.jetbrains.com/idea/[IntelliJ IDEA]. Añade un editor BPMN/DMN directamente al entorno de desarrollo, junto con funciones adicionales para generación de código, navegación y otras tareas.

==== Tasklist
Una plantilla de aplicación basada en React para gestionar tareas de usuarios finales. El código fuente está disponible en https://github.com/flowset/flowset-tasklist-react-community[GitHub].
