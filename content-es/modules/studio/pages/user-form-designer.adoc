= Diseñador de formularios de usuario

Usa el Diseñador de formularios de Flowset para editar Camunda Forms en IntelliJ IDEA. El Diseñador de formularios se abrirá cuando abras un archivo .form existente. Si creas un nuevo formulario con Flowset Studio, se abrirá automáticamente en el Diseñador.

image::form-designer.png[]

La interfaz del Diseñador de formularios consta de:

[cols="3,1,11", frame=none, grid=rows]
|===
| *Acciones de formulario*
| (1)
| Panel de acciones disponibles para el formulario.
| *Paleta de componentes*
| (2)
| La paleta de componentes proporciona un conjunto completo de elementos para crear formularios.
| *Modos del editor*
| (3)
| Panel para seleccionar el modo de vista. Hay tres modos disponibles: solo JSON, JSON y formulario, o solo formulario.
| *Lienzo*
| (4)
| Espacio de trabajo para crear un formulario.
| *Inspector de formularios*
| (5)
| El panel del inspector muestra los atributos del elemento seleccionado y permite editarlos.
| *Botón de visibilidad*
| (6)
| Control para mostrar u ocultar el inspector.
|===

== Editor de formularios

El editor de formularios permite crear formularios directamente en el IDE.

=== Operaciones básicas

[cols="1,3", frame="none", grid="rows"]
|====
| *Añadir elemento*
| Arrastra un nuevo elemento desde la Paleta de componentes al lienzo.
| *Cambiar el orden de los elementos*
| Arrastra el elemento a un nuevo lugar del formulario.
| *Eliminar elemento*
| Selecciona el elemento en el lienzo (haz clic en el elemento) y haz clic en el icono de papelera.
|====

== Panel de propiedades (Inspector de formularios)

image::form-designer-inspector.png[width=450px]

El panel de propiedades permite modificar los parámetros del elemento de formulario seleccionado. Si no hay ningún elemento seleccionado, se muestran las propiedades del formulario.

[cols="6,3,20", frame="none", grid="rows"]
|====
| *Búsqueda*
| (1)
| Busca un atributo por su nombre; al hacer clic en el icono se muestra un historial de búsqueda desplegable.
| *Enlace <empty>*
| (2)
| Abre un cuadro de diálogo para editar texto de varias líneas. Si el texto ya está definido, la primera línea se muestra como un enlace.
| *`+` (más)*
| (3)
| Abre un cuadro de diálogo para establecer una propiedad o un asistente para generar un elemento.
|====

== Despliegue

El editor de formularios permite desplegar el formulario en un motor Camunda/Operaton remoto.
Para abrir el asistente de despliegue, haz clic en el icono del cohete en la barra de herramientas del editor (panel Form Actions).
Se requiere una conexión a un motor externo configurada correctamente.

image::form-deployment-wizard.png[width=80%]

[cols="1,3", frame=none, grid=rows]
|====
| *Deployment name*
| Un nombre único para identificar el paquete de despliegue. Permite encontrar y administrar fácilmente una versión concreta del recurso en el sistema.
| *Enable duplicate filtering*
| Filtrado a nivel de archivo individual. Omite el redespliegue de recursos sin cambios (p. ej., diagramas BPMN) dentro de un despliegue. Ahorra espacio en la base de datos al evitar la creación de duplicados.
| *Deploy changed only*
| Filtrado a nivel de todo el paquete de despliegue. Si ningún archivo del despliegue ha cambiado, la operación se ignora por completo. Garantiza la idempotencia y evita la creación innecesaria de versiones del recurso.
| *Deployment source*
| El origen desde el que se inició el despliegue (p. ej., 'Flowset Studio'). Se utiliza para la auditoría y el seguimiento del origen de los despliegues.
| *Tenant ID*
| El identificador de tenant para una arquitectura multitenant. Permite aislar procesos y datos de diferentes clientes o departamentos dentro de un único clúster de Camunda.
|====
