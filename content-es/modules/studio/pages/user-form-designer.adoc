= Diseñador de formularios de usuario

Utilice el Diseñador de formularios de Flowset para editar Camunda Forms en IntelliJ IDEA. El Diseñador de formularios aparecerá cuando abra un archivo .form existente. Si crea un nuevo formulario a través de Flowset Studio, se abrirá automáticamente en el Diseñador.

image::form-designer.png[]

La interfaz del Diseñador de formularios de usuario consta de:

[cols="3,1,11", frame=none, grid=rows]
|===
| *Acciones de formulario*
| (1)
| Panel de acciones disponibles para el formulario.
| *Paleta de componentes*
| (2)
| La Paleta de componentes proporciona un conjunto completo de elementos para construir formularios.
| *Modos de editor*
| (3)
| Panel para seleccionar el modo de vista. Hay tres modos de vista disponibles: solo JSON, JSON y formulario, solo formulario.
| *Lienzo*
| (4)
| Espacio de trabajo para crear un formulario.
| *Inspector de formularios*
| (5)
| El panel del inspector muestra los atributos del elemento seleccionado y permite editarlos.
| *Botón de visibilidad*
| (6)
| Alternador de visibilidad del inspector.
|===

== Editor de formularios

El editor de formularios permite construir formularios directamente en el IDE.

=== Operaciones básicas

[cols="1,3", frame="none", grid="rows"]
|====
| *Añadir elemento*
| Arrastre y suelte un nuevo elemento desde la Paleta de componentes al lienzo
| *Cambiar el orden de los elementos*
| Arrastre y suelte el elemento a un nuevo lugar del formulario
| *Eliminar elemento*
| Seleccione el elemento en el lienzo (haga clic en el elemento) y haga clic en el icono de la papelera
|====

== Panel de propiedades (Inspector de formularios)

image::form-designer-inspector.png[width=450px]

El panel de propiedades permite modificar los parámetros del elemento de formulario seleccionado. Si no hay ningún elemento seleccionado, se muestran las propiedades del formulario.

[cols="6,3,20", frame="none", grid="rows"]
|====
| *Búsqueda*
| (1)
| Busca un atributo por su nombre; al hacer clic en el icono se muestra un historial de búsqueda desplegable.
| *Enlace <empty>*
| (2)
| Abre un cuadro de diálogo para editar texto de varias líneas. Si el texto ya está definido, la primera línea se muestra como un enlace.
| *`+` (más)*
| (3)
| Abre un cuadro de diálogo para establecer una propiedad o un asistente para generar un elemento
|====

== Despliegue

El editor de formularios permite desplegar el formulario en un motor Camunda/Operaton remoto.
Para invocar el asistente de despliegue, haga clic en el icono del cohete en la barra de herramientas del editor (panel Form Actions).
Se requiere una conexión correctamente configurada a un motor externo.

image::form-deployment-wizard.png[width=80%]

[cols="1,3", frame=none, grid=rows]
|====
| *Deployment name*
| Un nombre único para identificar el paquete de despliegue. Permite encontrar y administrar fácilmente una versión concreta del proceso en el sistema.
| *Enable duplicate filtering*
| Filtrado a nivel de archivo individual. Omite el redespliegue de recursos sin cambios (p. ej., diagramas BPMN) dentro de un despliegue. Ahorra espacio en la base de datos al evitar la creación de duplicados.
| *Deploy changed only*
| Filtrado a nivel de todo el paquete de despliegue. Si ningún archivo del despliegue ha cambiado, la operación se ignora por completo. Garantiza la idempotencia, excluyendo la creación innecesaria de versiones del proceso.
| *Deployment source*
| El origen desde el que se inició el despliegue (p. ej., 'Flowset Studio'). Se utiliza para la auditoría y el seguimiento del origen de los despliegues.
| *Tenant ID*
| El identificador de tenant para una arquitectura multi-tenant. Permite aislar procesos y datos de diferentes clientes o departamentos dentro de un único clúster de Camunda.
|====
