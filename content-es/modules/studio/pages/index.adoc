= Studio

*Flowset Studio* permite a los desarrolladores aprovechar el ecosistema de Java y Spring Boot para crear aplicaciones empresariales con un enfoque BPMN. Flowset Studio ofrece una herramienta todo en uno para cubrir el ciclo completo, desde el modelado hasta el despliegue.

*Funciones principales*

* Estructura de proyecto explícita
* Navegación entre objetos relacionados con el proceso
* Trabajo con procesos locales y remotos
* Búsqueda inteligente
* Modelador de procesos de negocio
* Autocompletado inteligente de código y validaciones
* Generación de servicios y Java Delegates
