== Características principales

* *Gestión de tareas* – visualización, filtrado y finalización de tareas asignadas al usuario
* *Gestión de procesos* – visualización de procesos disponibles e inicio de nuevas instancias
* *Integración flexible* – compatibilidad con la API REST de los motores BPM más populares (Camunda 7, Operaton)
* *Compatibilidad con formularios personalizados* – posibilidad de conectar componentes React como formularios personalizados
* *Interfaz moderna* – desarrollada con React y Ant Design, con diseño adaptable
* *Configuración sencilla* – configuración basada en el entorno e imágenes Docker listas para usar

== Tecnologías utilizadas

Flowset Tasklist está construido con las siguientes bibliotecas y frameworks:

. https://react.dev/[React]
. https://ant.design/[Ant Design]
. https://tanstack.com/query/latest[react-query]
. https://bpmn.io/toolkit/form-js/[form-js]
. http://vite.dev/[Vite]

[NOTE]
====
*Flowset Tasklist* no incluye un componente de backend, pero es totalmente compatible con la API REST de los motores BPM (Camunda 7, Operaton).
====
