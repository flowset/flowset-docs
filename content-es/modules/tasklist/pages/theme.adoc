= Tema

*Flowset Tasklist* utiliza la biblioteca https://ant.design/[Ant Design] como base de su interfaz.
Esto proporciona una interfaz moderna, adaptable y personalizable.

Puedes modificar la apariencia de Tasklist ajustando el tema a la marca y al estilo de tu organización.

== General

Ant Design admite los denominados *design tokens*: variables que definen colores, fuentes, espaciado y otros parámetros de estilo.
En Flowset Tasklist, todos los ajustes del tema se encuentran en un único archivo:

[source,shell]
----
src/features/theme/flowsetTheme.ts
----

== Modificar el tema

. Abre el archivo:
+
[source,shell]
----
src/features/theme/flowsetTheme.ts
----
. Localiza el objeto que contiene los design tokens (por ejemplo, `colorPrimary`, `borderRadius`, `fontFamily`).
. Cambia los valores de los parámetros según tus necesidades.

=== Ejemplo de modificación del color principal

[source,typescript]
----
export const flowsetTheme = {
  token: {
    colorPrimary: '#0A84FF',     // primary interface color
    colorBgBase: '#FFFFFF',      // background color
    colorTextBase: '#1F1F1F',    // main text color
    borderRadius: 8,             // border radius
  },
};
----

Después de guardar los cambios, reinicia la aplicación: Tasklist aplicará automáticamente el nuevo esquema de colores.

Para obtener más detalles, consulta la documentación oficial de Ant Design:
https://ant.design/docs/react/customize-theme
